# Wendy's Soda 

Aplicación web full-stack con frontend y backend separados , desplegada en vercel 

## Estructura
- `frontend/`: interfaz de usuario
- `backend/`: API y lógica del servidor

# Características 
- Este proyecto se encarga de llevar el control de cobros y consumo en una pequeña soda en guanacaste
- Se desplego el frontend en vercel y la base de datos en neon


#Tecnologias
-JS
-React 
-Node.js 
-Express 
-ORM
-SQL y POSGRE
